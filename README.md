# Web Calculator Project

A responsive and interactive Web Calculator built using HTML, CSS, and JavaScript. Developed as part of an internship assignment to demonstrate core front-end web development skills.

## 🚀 Live Demo
You can view the live project here:  
https://kumarsandeep71354-ops.github.io/calculator/

## 🛠️ Technologies Used
* **HTML5:** Structure and markup  
* **CSS3:** Styling and responsive UI design  
* **JavaScript (ES6):** Calculation logic and DOM manipulation  

## ✨ Features
* Basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
* Percentage calculation and clear/delete functions
* Clean, responsive user interface suitable for both mobile and desktop screens

## 📁 Repository Structure
* `index.html` - The HTML document structure
* `style.css` - Custom styling and design logic
* `script.js` - Dynamic UI handling and calculation functionality
